# 译文审校

审校分两阶段：首先逐段对照原文，修正可核实的问题；然后脱离原文，从目标语言读者的视角通读并润色译文。两阶段方法不同，但目的互补——对照审校确保准确性，通读润色使译文读起来像高质量的原创作品。

## 流程

### 情况一：承接翻译流程

翻译执行完成且用户确认进入审校后：

1. 若 `draft.md` 不存在，主 agent 将当前 `translation.md` 复制为 `draft.md`，作为增强流程开始前的译稿快照；若已存在，保留原快照。
2. 主 agent 按下文「subagent 审校提示」组装 prompt，委派 subagent 执行对照审校，产出 `critique.md`。
3. 主 agent 读取 `critique.md`，逐条回源核实：剔除不成立的条目，将核实后的报告写回 `critique.md`；若无问题则直接执行下一步。
4. 主 agent 按 `critique.md` 修订 `translation.md`。
5. 对照修正完成后，主 agent 按「通读润色」节的规则对修订后的译文做深度润色，保存为 `translation.md`。

### 情况二：用户直接提供原文与译稿

用户直接提供原文与已有译稿时，主 agent 全程执行审校：

1. 将原材料按主流程规范化为 Markdown 并确定输出目录。
2. 将用户提供的译稿复制保存为 `draft.md`。
3. 主 agent 严格对照原文与译稿，按审校要点逐段检查，生成 `critique.md`。
4. 主 agent 基于 `critique.md` 修订。
5. 对照修正完成后，主 agent 按「通读润色」节的规则对修订后的译文做深度润色，保存为 `translation.md`。

## 对照审校的原则与要点

逐段对照原文与译稿。审校只记录可回源证伪的问题，不要求译文与原文在结构和版式上逐项同构。为提升可读性而添加的小标题、加粗、分段或分隔线、`（注：）` 式补充说明，以及中文排版和标点规范化，不视为增译；仅当这些处理引入事实错误、改变原意、增添原文不存在的观点或论证，或明显误导读者时，才记为问题。

**准确与完整**

- 准确性：事实、数据、观点、逻辑关系和论证结构无偏移。
- 完整性：无漏译、无内容性增译、无跳段、无重复。

**可读性**

- 歧义结构：僵硬套用原文词序或句式导致修饰关系错乱、指代不明或多义解读的，标记为问题。
- 长句阻塞：因不分解原文长句而导致逻辑关系难以辨认的，标记需拆分的位置。

**语域与语气**

- 情感匹配：准确传达原文情感浓度和体裁风格。
- 特殊修辞：保留反讽、幽默或特定人格化语气。

**术语一致性**

- 如有 `glossary.md`，则以其为基准。若发现其中某条术语的译法存在问题（如不符合行业标准、与上下文冲突、或在译稿中显得突兀）记录问题并建议替代译法。
- 专业术语/人名/书名首次出现时，在译文后用括号标注原文。全文只标注一次，不可重复。

**Markdown 格式**

标题、列表、链接、图片、代码块、脚注等结构性标记完整保留。

## 诊断报告格式（`critique.md`）

仅记录可证伪的问题。某类无问题可省略该节，禁止为填满模板而编造问题。参考格式：

```markdown
## ...
- [问题]：[位置] — [描述]

## ...
- [问题]：[示例] → [建议修改]
```

若存在存疑的术语条目，单独一节列出：

```markdown
## 存疑术语

- [术语原文]：[当前译法] — [存疑原因] → [建议替代译法]
```

## subagent 审校提示

仅用于情况一。主 agent 按以下模板组装 prompt 并委派 subagent：

```text
你是译文审校者，请读取以下材料并输出 critique.md，严禁修改其他任何文件。

- 原文：{原文路径}
- 待审译稿：{output_dir}/translation.md
- 术语表：{output_dir}/glossary.md
- 输出：{output_dir}/critique.md

## 审校目标

{主 agent 在此内联审校目标：目标语言、目标读者、语域要求、本轮侧重点等。3-5 句。}

## 审校原则与要点

{{...}}

## 诊断报告格式

{{...}}
```

组装时，将上文「对照审校的原则与要点」和「诊断报告格式」两节的完整内容分别替换 prompt 中对应的 `{{...}}` 占位符，再发送给 subagent。

**注意**：有术语表时才提供 `- 术语表：{output_dir}/glossary.md`，否则不添加这段内容。

## 润色

> **注意**：本节内容仅适用于目标语言为中文的场景。若目标语言非中文，以下规则不用强行遵守。

完成对照修正后，摆脱原文束缚，将译文视为独立原创文章。从中文母语读者的视角通读全文，并进行深度润色。

### 前置判断：文体校准

动手前先判断译文的文体类型，据此调整规则 1–3 的执行强度：

- **观点推进型**（叙事、评论、随笔、演讲等）：全额执行。
- **逻辑密集型**（哲学论文、理论著作等）：降为半额，慎重拆句，保留论证链条的长句结构。
- **精确性优先型**（法律、合同、技术文档等）：降为最低，仅修正最明显的翻译腔。
- **文学性文本**（抒情散文、诗歌等）：规则 1、3 不强制，以保护原文韵律为首要原则。

规则 4 始终全额执行，不受文体影响。文体判断只作为内部执行依据，不生成中间文件。

### 润色规则

1. **消除翻译腔**：拆分冗长的从句，多用短句；删减不必要的代词（他/它/这/那）和连词；将具有被动意味的句子改为主动句。
2. **优化文气与节奏**：根据中文表达习惯，适当使用四字词语或成语，增强句子的节奏感；修复读起来明显卡顿的句间过渡和断裂的段落衔接。
3. **隐性逻辑重构**：删去生硬的“然而、因此、而且”等过渡词，让句子之间的逻辑通过语意自然流露。
4. **符合中文语境**：确保隐喻、俚语和文化参照符合中国读者的认知习惯；过于冗长的段落根据语义自然分段。

已自然通顺的句子保留，不为了用规则而改动。
